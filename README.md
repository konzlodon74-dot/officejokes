> "The printer only jams when the boss is standing right behind me, so I now email my deadlines straight to its repair guy."

## How it works

`main.py` (Python 3, standard library only, no network) holds the joke as a
single string constant. Before writing anything it asserts the bounty rules:
the line is non-empty, contains no newline or carriage return (exactly one
line), and is between 1 and 200 characters long. It then creates `/output`
if needed and writes the line to `/output/entry.txt` with no trailing
newline, so the file contains exactly the one line. Run it with
`python3 main.py`.
